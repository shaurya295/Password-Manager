# Password Manager

**APP Course - End Semester Project**

A desktop Password Manager application built with Python and Tkinter.

## Features
- Master password protection (SHA-256 hashed)
- Add, view, search, and delete saved passwords
- Random password generator
- Copy password to clipboard
- SQLite database for persistent storage
- Base64 encoding of stored passwords

## How to Run
```
python password_manager.py
```

## Technologies Used
- **Python 3** — Programming Language
- **Tkinter** — GUI Framework (built-in)
- **SQLite3** — Database (built-in)
- **hashlib** — Password hashing (built-in)
- **base64** — Password encoding (built-in)
